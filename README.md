# Booki

Booki est un projet front-end réalisé dans le cadre de la formation OpenClassrooms. L'objectif est de développer l'interface d'un site permettant aux utilisateurs de rechercher des hébergements et des activités dans la ville de leur choix.

## Fonctionnalités principales

- **Recherche d’hébergements** : Formulaire de recherche avec suggestions de villes.
- **Filtres dynamiques** : Filtres visuels pour affiner la recherche (économique, familial, romantique, etc.).
- **Affichage responsive** : Adaptation de l’interface pour ordinateurs, tablettes et mobiles.
- **Section activités** : Présentation des activités à faire dans la ville sélectionnée.
- **Design moderne** : Utilisation de la police Raleway et d’icônes Font Awesome.

## Technologies utilisées

- **HTML5** : Structure des pages.
- **CSS3** : Mise en forme, Flexbox, Media Queries pour le responsive.
- **Font Awesome** : Icônes pour les filtres et la navigation.
- **Google Fonts** : Police Raleway.

## Installation

1. **Cloner le dépôt**  
   ```bash
   git clone https://github.com/votre-utilisateur/booki.git
   ```
2. **Ouvrir le projet**  
   Ouvrez le dossier du projet dans votre éditeur de code préféré.

3. **Visualiser le site**  
   Ouvrez le fichier `index.html` dans votre navigateur.

Aucune dépendance supplémentaire n’est requise (tout est géré via CDN pour les polices et icônes).

## Structure du projet

- `/images` : Images du site (logo, photos d’hébergements, activités, etc.)
- `/css/style.css` : Feuille de style principale
- `index.html` : Page principale du site

## Consignes d’utilisation

- **Navigation** : Utilisez la barre de navigation pour accéder rapidement aux sections “Hébergements” et “Activités”.
- **Recherche** : Entrez une ville dans la barre de recherche pour simuler la recherche d’hébergements.
- **Filtres** : Cliquez sur les filtres pour afficher les hébergements selon vos critères.
- **Responsive** : Testez le site sur différentes tailles d’écran pour vérifier l’adaptabilité.

## Remarques

- Ce projet est une maquette front-end : il n’y a pas de connexion à une base de données ni de logique back-end.
- Les résultats de recherche et les filtres sont statiques et servent uniquement à présenter l’interface utilisateur.
